## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dinesh-data-engineering-portfolio.git
```

Navigate to the project directory:

```bash
cd dinesh-data-engineering-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create production build:

```bash
npm run build
```
